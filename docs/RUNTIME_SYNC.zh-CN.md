# 通用运行时更新：2026-10-15

本批按功能移植，不用部署目录覆盖公开源码。Windows 进程锁、BYOK/provider_execution、可配置模型和本地部署能力保持；眼镜模块不在本批内。

## 已同步

- **调度恢复**：临时 scope lane 争抢采用有限退避，最长等待约 60 秒且响应停止事件；合并正在运行或本轮已入队时不同时启动同 scope 的重建索引。被取消的自动维护任务使用五分钟桶重试键，失败的任务仍需显式审计重试。
- **删除语义**：删除消息对应的 Source 或会话时，在同一个事务内保存 scope 绑定的消息身份哈希。相同外部消息身份更换 session/请求幂等键后仍被拒绝；不同 scope 不相互封禁。内部消息 ID 不再误匹配另一条消息的外部 ID。计费正文清理仍执行，已完成 ingest 的无正文 completion fence 保留，避免后续索引误判写入未完成。
- **Slow Graph**：完整但校验失败的模型提议允许该路由一次纠错，随后执行相同严格验证；第二次无效或网络失败直接终止。Flash 显式升级 Pro 时仍遵守路由约束。`TMCRA_SLOW_GRAPH_TIMEOUT_SECONDS` 仅供本地 Slow 路由，默认 300 秒，范围 `(0, 900]`；远程默认 90 秒。
- **可观察性**：工作人员状态聚合每个 scope 最近一次成功/失败 consolidation；正在运行或取消的重试不会掩盖旧失败。返回计数，不返回 scope 身份或原始异常正文。
- **网页**：记忆图谱按需加载。新个人 API key 与 Codex/Harness token 默认仅 `memory:read`、`memory:write`、`memory:feedback`；个人 key 显式请求 `memory:consolidate` 返回 422。既有 token 不自动撤销，人工 consolidation 应使用专门配置的服务凭据。

## 验证与兼容性

新增测试使用合成 SQLite、确定性模型边界和本机 HTTP。覆盖重导入、跨 scope、事务回滚、ID 别名冲突、调度竞争、严格纠错、聚合健康以及 token 权限。模型别名/便携部署与原有反馈、BYOK 清理测试一并运行。服务 shared-core manifest 仅更新实际修改的 Slow Graph 文件哈希，冻结 benchmark 目录及权重不修改。

哈希撤销标识不保存消息正文；它不是内容相似度黑名单，也不声称匿名性。全新身份不会仅因正文相同而被拒绝。升级前已物理抹除且没有撤销记录的历史身份不会凭空恢复。整个 scope 删除/重建、备份恢复与跨进程部署需独立验收。

本批不切换正在运行的服务。回退源码不会自动删除撤销表；旧代码不执行新增的重放保护，因此实际数据环境的降级应先评估这个行为差异。测试副本回滚不等于线上数据回滚。

## 后续独立批次

共享控制库正文拆分需要迁移、迁移失败恢复与跨平台文件权限验证；不随本批默认启用。团队历史导入的归属校验、特定模型 Writer slot/attribution 配置，以及完整网页/MCP 接入面板另行拆分，避免引入团队专用依赖。`tmcra-memory` 按 owner-local 语义维护，不引入共享租户服务或线上控制面。
